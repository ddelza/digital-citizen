# 미래를 여는 디지털 시민 · 2단원 상호작용 사이트

2단원 「디지털 기술의 이해와 활용」(교과서 pp.26~43) 수업에서 학생들이 함께 활동하는 페이지 모음입니다.
정적 GitHub Pages 사이트이고, 데이터는 Firebase Realtime Database(`gwangsu-on`)에 REST로 저장합니다. 빌드 단계는 없습니다.

- 학생: `index.html`에서 학번(4자리)과 이름으로 입장 → 차시별 활동
- 교사: `teacher.html` (비밀번호) — 반별 제출 현황, 학생별·활동별 응답, CSV 내보내기
- 데이터 경로: `years/{year}/dcitizen/u2/{s차시/활동}/{학년-반}/{학번}`
- 공용 라이브러리: `dc.js` (개인 응답 폼, 우리 반 게시판·좋아요·댓글, 집계 막대)
