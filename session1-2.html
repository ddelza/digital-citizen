💾 디지털 기술 (p.29)

문자·소리·이미지 등의 정보를 0과 1로 표현하여 처리·저장·전달하는 기술이에요. 디지털 기기는 하드웨어와 소프트웨어가 함께 작동해요.

구분뜻예
하드웨어정보를 처리하거나 소프트웨어를 실행하는 물리적 장치스마트폰, 노트북, 태블릿
소프트웨어하드웨어에서 실행되어 다양한 기능을 수행하는 프로그램메모 앱, 웹 브라우저, 동영상 앱

💡 눈에 보이고 손으로 만질 수 있으면 하드웨어, 그 안에서 돌아가는 프로그램이면 소프트웨어!

🤖 인공지능과 생성형 인공지능 (p.29)

입력된 정보를 바탕으로 추론하여 결과를 예측하거나 대상을 분류하고, 정보를 추천하거나 새로운 내용을 생성하는 기술이에요. 그중 생성형 인공지능은 학습한 데이터의 패턴을 바탕으로 글·이미지·소리 등 새로운 콘텐츠를 만드는 인공지능이에요.

구현 방식특징예
규칙 기반사람이 판단 규칙을 직접 정함규칙 기반 챗봇, 전문가 시스템
기계학습 기반데이터에서 패턴을 학습함사진 분류, 음성 인식, 생성형 인공지능

실제 인공지능 시스템은 두 방식을 함께 쓰기도 해요.

인공지능인간의 인지 활동을 모방한 기술 추론학습한 패턴으로 새 입력을 판단·예측하는 것 학습대량의 데이터를 분석해 규칙·패턴을 스스로 익히는 것 패턴데이터 속에 반복되는 규칙·특징

📶 무선 네트워크 (p.30)

케이블 없이 데이터를 주고받게 하는 통신 방식이에요.

구분와이파이(WiFi)블루투스(Bluetooth)
연결 방법주로 무선 공유기를 통해 네트워크에 연결주로 가까운 기기끼리 직접 연결
주요 특징일반적으로 전송 속도가 빠르며 대용량 데이터를 주고받기에 적합일반적으로 전력 소비가 적으며 가까운 기기 사이에서 소용량 데이터를 주고받기에 적합
활용 예인터넷 검색, 온라인 동영상 시청, 클라우드 파일 공유무선 이어폰·키보드 연결, 가까운 기기 사이 파일 전송

와이파이는 인터넷 자체가 아니라 기기를 무선 네트워크에 연결하는 기술이에요. 실제 성능은 기기 규격과 사용 환경에 따라 달라요.

🌐 초연결 환경과 데이터 센터 (p.30)

사람·사물·정보가 네트워크로 촘촘히 연결되어 끊임없이 데이터가 오가는 환경이에요. 우리의 요청은 데이터 센터(대규모 서버·저장장치를 갖춘 시설)의 서버에서 처리되어 결과가 기기로 돌아와요.
